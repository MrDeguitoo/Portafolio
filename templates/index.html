Proyectos Destacados

GestionInventario-Fullstack

Proyecto académico colaborativo • Java/Spring Boot

Reinvención del sistema de gestión desarrollado anteriormente, orientada a la gestión de inventario de un taller mecánico. El proyecto implementa una arquitectura de 10 microservicios independientes utilizando Java, Spring Boot y Spring Cloud, centralizados mediante un API Gateway y protegidos mediante autenticación JWT. La información se gestiona mediante MySQL, con una base de datos independiente por microservicio, mientras que Docker y Docker Compose se utilizan para la contenerización de la infraestructura.

Taller-IA

Proyecto académico colaborativo • IA/RAG

Sistema de IA para talleres mecánicos que transforma diagnósticos técnicos en explicaciones simples para los clientes. Utiliza RAG (Retrieval-Augmented Generation) para consultar documentación técnica antes de generar las respuestas. El procesamiento se ejecuta 100% de forma local mediante Ollama, utilizando un backend FastAPI, frontend React y una base vectorial ChromaDB. También incorpora monitoreo de latencia, errores y consultas realizadas.

Experiencia

Sistema web para gestión y registro de vehículos

Proyecto para Taller Mecánico • Práctica profesional

2025

Sistema web desarrollado para RSM Automotriz con el objetivo de centralizar y facilitar la gestión de la información de los vehículos atendidos por el taller, reemplazando parte de los registros manuales realizados en papel. El sistema permite registrar, buscar y actualizar vehículos mediante su número de patente, además de asociar imágenes a cada registro. La aplicación fue desarrollada con Python y Flask, utilizando PostgreSQL para almacenar la información.

  • Registro y actualización de vehículos.
  • Búsqueda mediante número de patente.
  • Asociación de imágenes a los registros.
  • Almacenamiento de información en PostgreSQL.
  • Interfaz enfocada en la simplicidad y facilidad de uso.
Python Flask HTML CSS PostgreSQL
